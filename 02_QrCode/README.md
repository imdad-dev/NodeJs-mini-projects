# QR Code Generator

A simple and user-friendly web application that generates QR codes from text or URLs with customizable color and size.

## Features

- Generate QR code from any text or URL
- Custom foreground color selection
- Adjustable QR code size (in pixels)
- Instant preview of generated QR code
- Direct download button for the QR code image
- Clean and responsive user interface
- Error handling for invalid inputs

## Technologies Used

- **Backend**: Node.js + Express.js
- **Templating Engine**: EJS
- **QR Code Generation**: qrcode (npm package)
- **Frontend**: HTML5, CSS3
- **Form Handling**: HTML forms + POST method
